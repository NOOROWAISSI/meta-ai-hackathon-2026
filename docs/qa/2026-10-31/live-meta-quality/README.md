## Isolated prompt correction and rerun

The follow-up says unknown facts alone do not imply no useful work, asks for small untimed clarification/exploration tasks tied to the accepted goal, and reserves zero tasks for an actual no-useful-work reason. It also prevents comparing total effort directly with weekly hours to declare feasibility unknown. The app still owns schedule assessment. No tasks are added, padded, estimated or committed by application code.

| Scenario | Result | Qualitative review |
|---|---|---|
| unknown-facts, first rerun | 2 tasks / 3.5 h / untimed | 2/2/2/1/2. Pending-confirmation checklist plus explicitly exploratory option map; no assumed criteria, skills, sources, eligibility or schedule. |
| unknown-facts, independent repeat | 2 tasks / 2.5 h / untimed | 2/2/2/1/2. Same useful clarification/exploration pattern without inventing reviewed resources. Different estimates demonstrate run variability. |
| mandatory-missing | 3 tasks / 9 h / fits diagnostic | 2/2/2/1/2. Recording remains separate from verified-channel submission and receipt, both targeting the mandatory requirement. |
| beginner-limited | 4 tasks / 7.5 h / infeasible | 2/2/2/1/2. Critical path, learning time, deferrals and a scope/availability decision remain. Optional remove-task interaction expands the minimal flow slightly; it is goal advice, not an organizer requirement. No fit promise. |

Observed improvement in the affected scenario supports review of the prompt correction. It does not prove estimates improved, establish model reliability, or remove the need for organizer/source confirmation. Only affected scenarios were rerun after the correction; the other three baseline scenarios were not repeated with the new prompt.
